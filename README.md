# Funky Blog - Backend API

RESTful API and backend service powering the Funky Blog application. Built with Laravel and MySQL to manage authentication, blog posts, categories, and media assets.

### 🛠️ Tech Stack
* **Framework:** Laravel
* **Language:** PHP 8.4
* **Database:** MySQL
* **Tools:** Composer
